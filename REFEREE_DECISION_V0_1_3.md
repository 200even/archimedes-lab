# Referee Decision — V0.1.3

**Decision:** AUTHORIZE NEXT IMPLEMENTATION STAGE

The V0.1.3 safeguards are accepted for implementation of the agent layer only. This authorization does not permit benchmark exposure.

## Accepted safeguards

- A2 inferred cardinality under the hard cap `k_max <= floor(sqrt(|E|))`.
- B2 same-domain distractor operators.
- One-shot, budget-priced A and B visible-fit gates.
- SMT/Z3 finite truth-table non-isomorphism adjudication.
- Frozen finite representation geometry for V0 D4.

## Binding interpretation

V0 tests discovery of a reusable explanatory abstraction **within a preregistered finite representational geometry**. It does not establish D5 representational-geometry invention.

Exact recovery of the generator's cardinality is a secondary diagnostic, not implied by D4 success.

## Additional required diagnostic

For every accepted A theory, record functional minimality. For each declared label `q`, compute its complete predicted A response signature over all eight interventions. If two labels have identical signatures, flag the theory as nonminimal and record the effective cardinality. This is diagnostic, not a new V0 kill gate.

## Authorized work

- stateless Conjecturer interface;
- stateless Critic interface;
- neutral AST-only role handoff;
- deterministic orchestration;
- Flat LLM+synthesis baseline interfaces;
- functional-minimality diagnostic.

## Not authorized

No causal-world, Null-world, comparative, or prompt-tuning model run may occur until a final pre-exposure freeze is reviewed. That freeze must contain exact prompts, model/version, sampling parameters, inference-call schedule, tool access, baseline parity, abstention semantics, false-positive rule, and cross-world statistical plan.
